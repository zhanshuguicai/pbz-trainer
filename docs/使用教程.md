# 影之刃零 修改器 · 使用教程（1.0.3）

照着这份教程一步一步做就能用起来，不需要懂编程。

---

## 0. 开始之前

- 本修改器**只适用于 Steam 版《影之刃零》的单机模式**，只在你自己的电脑上改游戏数据，不联网。
- 支持的游戏版本：Steam 版本号 **26266538** 和 **26367565**。游戏更新后，修改器会自动停用"改数值、改物品、自动弹反"这几项功能，以免出错，要等修改器更新后才能用。状态页能看到当前版本是否支持。
- **先备份存档**（推荐）。存档在游戏安装目录下的 `ProjectPBZ\Saved\SaveGames`，把整个文件夹复制一份到别处即可。第一次修改物品前，修改器也会自动备份一次。
- 系统要求：Windows 10 或 11，64 位。发布包已自带运行环境，**不需要另外安装 .NET**。

---

## 1. 下载和解压

1. 在 GitHub 的 Release 页面下载 `PBZTrainer-1.0.1-win-x64.zip`。
2. 右键 zip →"全部解压缩"，解压到一个**你自己好找的地方**，例如 `D:\影之刃零修改器`。
   - 不要解压到 `C:\Program Files` 里（那里写不进文件，修改器要在自己旁边保存设置）。
   - 路径里有中文没关系。
3. 解压后的文件夹里应该有：

| 文件 | 作用 |
|---|---|
| `PBZManager.exe` | 修改器本体，双击打开 |
| `安装加载器.bat` / `卸载加载器.bat` | 往游戏里装 / 移除 UE4SS 加载器（只需第一次装一次） |
| `loader\` | 加载器文件（UE4SS） |
| `payload\` | 游戏内模块，修改器会自动装进游戏，不用动它 |
| `使用教程.md`、`README.md`、`CHANGELOG.md` | 说明文档 |
| `SHA256SUMS.txt` | 所有文件的校验值 |

## 2. 第一次安装（三步）

> 这三步都要在**游戏关闭**的时候做。

### 第一步：安装加载器

1. 双击 **`安装加载器.bat`**。
2. 窗口里出现"已安装 N 个加载器文件"就成功了，按任意键关闭。
3. 可能遇到的提示：
   - **"PBZ.exe 不是验证过的版本"**：你的游戏版本还不受支持，先别继续。
   - **"目标文件已存在"**：你的游戏目录里已经装过 UE4SS（或别的 mod 加载器）。如果是之前装过本修改器的加载器，直接跳到第二步；否则请先自行确认那是什么。
   - **游戏不在默认位置**：脚本会自动从 Steam 的库列表里找游戏。实在找不到时，会提示你用 `-GameDir` 参数指定，见第 9 节"常见问题"。

### 第二步：打开修改器，安装游戏内模块

1. 双击 **`PBZManager.exe`**。
   - 第一次打开如果弹出 **"Windows 已保护你的电脑"**：点"**更多信息**"，再点"**仍要运行**"。这是因为程序没有付费的数字签名，不是病毒。
2. 停在 **"状态"** 页，看"游戏"这一栏：
   - 安装位置：显示你的游戏目录；
   - 版本校验：绿色的"已验证版本 ……"；
   - UE4SS 加载器：绿色的"已安装"；
   - PBZSuite：显示"未安装"。
3. 点 **"安装 / 更新"**。PBZSuite 那一行变成绿色的 **"已安装，与本程序版本一致"** 就好了。

### 第三步：开游戏

1. **保持修改器开着**（它要一直运行，功能才有效），然后从 Steam 启动游戏，进入存档。
2. 回到修改器"状态"页，看"实时状态"：
   - "连接"显示绿色的 **"实时"**；
   - 血量条在动，战斗、药的信息都有显示。

到这里就全部装好了。以后每次玩：**先开修改器，再开游戏**即可，不用重复第一、二步。

## 3. 各个功能怎么用

### 3.1 数值修改（血量 / 杀气 / 绝技能量 / 影魂点数）

1. 打开 **"数值修改"** 页。
2. 勾选想锁的项目（默认四项都勾）。
3. "固定为"一栏：
   - **留空** = 锁满（低于上限就补满）；
   - **填数字** = 固定为这个数（例如杀气填 200，就一直保持 200）。
4. 打开 **"启用（总开关）"**，或在游戏里按 **Ctrl+F1**。
5. "当前 / 上限"一栏会实时变化，旁边显示"游戏内已生效"。

> 每次打开修改器时总开关都是关的；关闭修改器时也会自动关掉。角色阵亡时不会把血补回来。

### 3.2 物品和钱

1. 游戏要开着并已进入存档。打开 **"物品"** 页，点 **"从游戏读取"**。
2. 列表里显示能改的材料（武器 / 杀器 / 饰品 / 药的强化材料、摄魂材料、核心养成材料）。去掉"只显示可修改的"可以看全部物品（其他只能看不能改）。
3. 在 **"改为"** 一栏填新数量，点 **"应用修改"**。也可以选中几行，点"选中项填 999"。
4. 改钱：在"钱"后面的"改为"里填数字，点 **"修改钱"**。
5. 状态栏会显示"已修改 N 项，游戏回读一致"。第一次修改前，存档会自动备份到修改器旁边的 `data\save-backups`。

### 3.3 战斗辅助（自动弹反 / 闪避）

1. 打开 **"战斗辅助"** 页，确认"弹反键"和"闪避键"与你游戏里的按键一致（默认：弹反 = 鼠标右键，闪避 = 左 Shift）。
2. 进入战斗，按 **F7**（或勾选"启用"）。听到上升的提示音就是开了。
3. 敌人出招时，修改器会在命中前一刻替你按一下弹反键；红光等只能闪避的攻击会按闪避。
4. **游戏窗口必须在最前面**（切到别的窗口时不会按键）。
5. 下方统计会显示弹反、闪避次数和"受击"次数。受击多的话，调一下"提前量"（默认 120 毫秒，可以试 60 或 200）。
6. 用手柄玩也能用：修改器按的是键鼠按键，游戏同样会响应，只是界面上的按键提示图标可能短暂切换成键鼠样式。

> 实测成功率大约 85%，不是百分之百。

### 3.3a 玩家工具（速度、伤害、无限药、飞行、传送）

1. 打开 **"玩家工具"** 页。数值框里 1 就是正常；改完按回车生效。
   - **游戏速度**：2 = 两倍速，0.5 = 慢动作。
   - **移动速度**：跑步、冲刺、走路一起变快。
   - **造成伤害**：填 100 接近一击必杀。**受到伤害**：填 0 就不会掉血。
   - **无限药**：身上装备的两种药一直是满的。
2. **飞行**：勾上（或按 Ctrl+F11）后角色没有碰撞，能穿墙。用 **Ctrl+↑ / Ctrl+↓** 上升、下降 2 米。落到地面上方再关掉飞行。
3. **传送**：站在想记住的地方按 **Ctrl+F9**（或点"记录当前位置"，可以先填个名字）。之后按 **Ctrl+F10** 传送到选中的记录点（没选就是最新的那个）。传错了点"撤销上次传送"。只能在同一张地图内传送。
4. 卡在地形里出不来：开飞行往上飞一点，或传送到记录点。
5. 点"全部恢复正常"一键还原。关闭修改器时也会自动还原。

> 等级与经验修改是试验功能，改之前建议先备份存档（关游戏后复制 `ProjectPBZ\Saved\SaveGames`）。

### 3.3b 场景修复（一次性机关关上后打不开）

1. 走到卡住的机关跟前（例如戏梦山庄挡住密道的那幅画）。
2. 打开 **"场景修复"** 页，点 **"扫描附近（20 米）"**。
3. 认识的机关会排在最前面并写明做法。选中它，点 **"打开 / 溶解"**，大约 3 秒后就能走过去。
4. 不认识的东西可以试"移除（隐藏并可穿过）"，不对就"恢复原样"。
5. 这些改动游戏不会存下来：读档后需要的话再做一次。

### 3.4 条件播放器（打到某个时刻自动放歌）

1. 打开 **"条件播放器"** 页，勾选"启用条件播放器"。
2. 点 **"添加规则"**，然后设置这一行：
   - **触发事件**：什么时候放（例如"Boss 血量跌破"）；
   - **参数**：例如填 50，表示 Boss 掉到一半血时（鼠标停在参数格上会显示说明）；
   - **附加条件**：点"编辑…"，可以要求"仅战斗中"、"仅 Boss 战中"、"血量低于 30%"等，全部满足才放；
   - **歌曲**：点"选择…"，可以一次选多首；
   - **播放设置**：点"设置…"，可以设音量、从第几秒开始放（跳过前奏）、循环还是只放一遍、淡入淡出、冷却时间，多首时随机还是轮流；
   - **优先级**：同时触发时只放数字最大的那一条；
   - **淡出条件**：发生什么事时把歌淡出（例如"Boss 战结束"），选"不淡出"就放完为止。
3. 点"试听选中"可以先听一下。

**示例：Boss 半血时放一首歌，打完 Boss 停**

| 列 | 填写 |
|---|---|
| 触发事件 | Boss 血量跌破 |
| 参数 | 50 |
| 歌曲 | 选你的歌 |
| 淡出条件 | Boss 战结束 |

**示例：喝空药时放一首（只在战斗中）**

| 列 | 填写 |
|---|---|
| 触发事件 | 药喝空 |
| 附加条件 | 编辑… → 战斗状态选"仅战斗中" |
| 淡出条件 | 战斗结束（任何原因） |

- 歌曲文件放在你自己电脑上，修改器只记录路径。换电脑后需要重新选择。
- "导出规则…"可以把整套规则存成文件备份，"导入规则…"可以读回来。

### 3.5 热键一览（都可以在对应页面点按钮修改）

| 功能 | 默认热键 |
|---|---|
| 数值锁定总开关 | Ctrl+F1 |
| 单独开关血量 / 杀气 / 绝技能量 / 影魂点数 | Ctrl+F2 / F3 / F4 / F5 |
| 自动弹反 / 闪避 | F7 |
| 停止当前歌曲 | Ctrl+F6 |
| 条件播放器开关 | Ctrl+F8 |
| 记录当前位置 / 传送到记录点 | Ctrl+F9 / Ctrl+F10 |
| 飞行开关 | Ctrl+F11 |
| 上升 / 下降 2 米 | Ctrl+↑ / Ctrl+↓ |

改热键：点热键按钮 → 按下新的组合键。Esc 取消，Backspace 清除。单个字母或数字键必须带 Ctrl / Alt / Shift。

## 4. 录屏时录到修改器的音乐

Win+G（Xbox Game Bar）默认**只录游戏声音**，修改器放的歌录不进去：

1. 按 **Win+G** → 点上方的**齿轮（设置）**→ 左侧 **"捕获"**；
2. **"要录制的音频"** 改成 **"全部"**。

或者用 Windows 自带截图工具录屏（**Win+Shift+R**），录前打开"系统音频"。也可以用 OBS 录制。

## 5. 游戏更新之后

- 修改器状态页的"版本校验"会变成黄色"未验证"，此时数值修改、物品、自动弹反会自动停用（条件播放器和状态显示一般仍可用）。
- 等修改器出新版本后再用。不要自己强行修改。

## 6. 修改器更新之后

1. 关闭游戏和旧修改器，把新版解压到原来的文件夹覆盖（`data` 文件夹里是你的设置，会保留）。
2. 打开修改器，在状态页点 **"安装 / 更新"**。
3. 如果"连接"一行出现橙色的"游戏内模块是旧版本"，说明还没更新成功，关游戏后再点一次"安装 / 更新"。

## 7. 卸载

1. 关闭游戏。在修改器"状态"页点 **"卸载"**，移除游戏内模块。
2. 双击 **`卸载加载器.bat`**，移除加载器。
3. 删除修改器文件夹即可。存档不受影响。

## 8. 设置和数据存在哪

全部在修改器旁边的 **`data`** 文件夹：

| 文件 | 内容 |
|---|---|
| `settings.json` | 条件播放器规则、音量 |
| `lock.json` | 数值修改、热键、战斗辅助设置 |
| `save-backups\` | 物品修改前的存档备份 |
| `events.log` | 事件与操作记录（排查问题用） |

## 9. 常见问题

**Q：PBZSuite 显示"存在来源不明的文件夹"或"文件被改过"？**
如果后面写着"都是本工具的文件，可点安装 / 更新覆盖"，直接点"安装 / 更新"并确认即可。否则说明游戏的 `ue4ss\Mods\PBZSuite` 里有别的文件，请自行检查。

**Q：热键按钮是红字 / 状态栏说"热键注册失败"？**
这个组合键被别的程序占用了（例如另一个修改器、录屏软件）。点按钮换一个组合键。

**Q：自动弹反完全没反应？**
确认：① 游戏窗口在最前面；② 战斗辅助页显示"游戏内已生效"；③ 弹反键、闪避键与游戏设置一致；④ 统计里"本程序已按键"的次数在增加。

**Q：Boss 事件没触发？**
Boss 战以屏幕上出现 Boss 血条为准。状态页的"战斗"一行，在 Boss 战时会显示 Boss 名字和血量；如果没有显示，请把修改器旁边的 `data\events.log` 和游戏目录下的 `ue4ss\UE4SS.log` 提交到 Issue。

**Q：杀毒软件报毒？**
加载器（UE4SS）通过 `dwmapi.dll` 注入游戏，修改器会模拟按键，部分杀毒软件可能误报。文件校验值见 `SHA256SUMS.txt`。

**Q：游戏不在默认的 Steam 位置，安装加载器找不到游戏？**
在修改器文件夹的地址栏输入 `powershell` 回车，然后执行（把路径换成你的）：

```bash
powershell -ExecutionPolicy Bypass -File install-loader.ps1 -Mode Install -GameDir "D:\SteamLibrary\steamapps\common\PBZ\platform\steam"
```

**Q：修改器必须一直开着吗？**
是的。条件播放器、热键、自动弹反都在修改器里运行。可以最小化。

**Q：出问题想全部还原？**
按第 7 节卸载，再用第 0 节备份的存档覆盖回去即可。
